# libuvcpp — Modern C++ wrapper for libuv

## Debian / Ubuntu

    sudo install -d -m 0755 /etc/apt/keyrings
    curl -fsSL https://antruly.github.io/libuvcpp/apt/key.asc |
      sudo tee /etc/apt/keyrings/libuvcpp.asc >/dev/null
    echo "deb [signed-by=/etc/apt/keyrings/libuvcpp.asc] https://antruly.github.io/libuvcpp/apt stable main" |
      sudo tee /etc/apt/sources.list.d/libuvcpp.list
    sudo apt update
    sudo apt install libuvcpp-dev

## Fedora / RHEL / openSUSE（dnf / zypper）

    sudo curl -fsSL -o /etc/yum.repos.d/libuvcpp.repo https://antruly.github.io/libuvcpp/rpm/libuvcpp.repo
    sudo dnf install libuvcpp-devel

## 预编译包（Linux x64 开发快照）

    https://antruly.github.io/libuvcpp/download/1.7.6-dev/libuvcpp-1.7.6-linux-x64.zip

自包含（除 glibc / libstdc++ 外无动态依赖），全模块：HTTP/1.1、HTTP/2、
HTTP/3（QUIC）、WebSocket、WSDL/SOAP、C API、Redis、SOCKS5，以及数据库层
（SQLite 内建；MySQL / PostgreSQL / ODBC / MongoDB 在运行时 dlopen 使用者
自装的那份客户端库，缺库返回 NO_DRIVER 而不影响进程）。

对应源码 `release/1.6.1` 分支 commit `738b4ad`（版本串 `1.7.6-dev`）。
同目录有 `SHA256SUMS` 与 `BUILD-INFO.txt`（构建配置、模块清单、运行要求）。
**这是开发快照，不是正式发布**：它由 Ubuntu 24.04 的工具链编译，需要
glibc >= 2.38；正式版本以 GitHub Releases 和下面的 apt / dnf 渠道为准。

## 文件

- `apt/` — Debian 仓库（`InRelease` 已签名）
- `rpm/` — RPM 仓库（`repomd.xml.asc`）
- `download/<版本>/` — 预编译包、`SHA256SUMS`、构建清单
- 源码与发布包：<https://github.com/Antruly/libuvcpp>

## 注意

这些包链接**系统的** `libuv` 与 `zlib`；GitHub Release 里的 zip 是自包含的，
两者不要混用（同一个进程里出现两份 libuv 是内存破坏风险）。
