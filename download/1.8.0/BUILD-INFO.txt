动态依赖
  libstdc++.so.6 / libgcc_s.so.1 / libm.so.6 / libc.so.6 —— 除此之外没有
  第三方动态库（libssl、libuv、libz、libnghttp2 … 全部静态编入）。
  因此本包要求 glibc >= 2.38、libstdc++ 的 GLIBCXX_3.4.32（GCC 13 运行时）：
  Ubuntu 22.04（glibc 2.35）不能直接用。GitHub Releases 上的正式包由 CI
  在 22.04 上编，下限更低。

数据库客户端库
  按仓库的驱动策略，MySQL / PostgreSQL / ODBC / MongoDB 四家**不随包分发**
  客户端库；运行时用 dlopen 打开使用者自己装的那一份。
  缺库时 open() 返回 NO_DRIVER，进程与 HTTP 服务照常运行。
  MongoDB 的搜索名：libmongoc-1.0.so.0 / libbson-1.0.so.0（1.x），
  libmongoc2.so.2（2.x）；可用 UVCPP_DB_MONGOC_LIBRARY /
  UVCPP_DB_BSON_LIBRARY 指定绝对路径。
  Redis 内置 RESP2/RESP3 客户端，不需要任何外部库。
